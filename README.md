# Onkar Purjalkar — Reference-inspired portfolio

This is a redesigned portfolio using your provided resume details and project descriptions. It uses plain HTML, CSS, and JavaScript, so no build step is required.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## Featured projects\n- **AIVICS** — AI virtual assistant with voice, vision, and automation features.\n- **MindCare.ai** — mental health score prediction from lifestyle and daily-habit factors.\n- **Vayu-Mitra** — air-quality prediction and pollution advisories.\n\n## Features
- Editorial dark design with lime accent
- Responsive mobile navigation
- Animated hero typography and orbit illustration
- Scrolling technology marquee
- Scroll-triggered section reveals
- Project category filters
- Active navigation and scroll progress
- Copy-email interaction
- Contact form that prepares an email draft (no backend needed)
- Reduced-motion support

## Before deploying
- The linked reference website did not expose readable rendered page content through the available browser inspection, so this is a fresh design direction rather than a pixel-perfect clone.
- Verify the project repository links. Some project cards currently use your GitHub profile as a placeholder.
- Add the exact AIVICS and chatbot repository URLs if they differ.
- Check that your resume PDF is up to date.
- For a contact form that sends without opening the visitor's email app, connect a form backend or email service.
